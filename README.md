## 🏢 Sobre Zoren Solution

**Zoren Solution** es una empresa de consultoría enfocada en la **seguridad inteligente**, utilizando cámaras e **Inteligencia Artificial (IA)** para detectar situaciones de riesgo y verificar el cumplimiento de medidas de seguridad.

Nuestro objetivo es transformar los sistemas tradicionales de videovigilancia en soluciones capaces de **analizar automáticamente lo que ocurre frente a una cámara**, ayudando a identificar situaciones que podrían representar un peligro.

Nuestro sistema centraliza estas soluciones bajo una plataforma denominada **Zoren Solution**, desde donde se gestionan y supervisan los diferentes proyectos de seguridad.

---

## 🎯 ¿Qué problema buscamos solucionar?

Los sistemas tradicionales de cámaras de seguridad permiten observar lo que ocurre en un determinado lugar, pero normalmente requieren que una persona esté observando constantemente las imágenes.

Esto puede dificultar la detección inmediata de situaciones como:

* 🚨 Una persona sufriendo una caída.
* 🖐️ Determinadas señas o gestos.
* 😷 Uso o ausencia de mascarilla.
* ⛑️ Falta de casco de seguridad.
* 🦺 Falta de chaleco de seguridad.
* 🧤 Falta de guantes.
* ⚠️ Incumplimiento del equipo de protección personal.
* 👷 Situaciones que puedan representar un riesgo para las personas.

**Zoren Solution busca automatizar parte de este proceso mediante Inteligencia Artificial.**

---

# 🤖 ¿Cómo funciona?

Nuestro concepto utiliza **cámaras conectadas a sistemas de Inteligencia Artificial capaces de analizar imágenes y detectar determinados eventos o características.**

### 📹 Cámara

La cámara captura imágenes del entorno que se desea supervisar.

⬇️

### 🧠 Inteligencia Artificial

El sistema analiza las imágenes y busca patrones previamente definidos.

⬇️

### 🔎 Detección

La IA puede identificar diferentes situaciones, dependiendo del proyecto implementado.

⬇️

### 🚨 Notificación / supervisión

Cuando se detecta una situación determinada, el sistema puede utilizar esta información para facilitar la supervisión y la respuesta ante el evento.

# 🚀 Proyectos realizados

## 1. 🚨 Fall Detection Lumen

**Fall Detection Lumen** es una solución orientada a la **detección de caídas mediante cámaras e Inteligencia Artificial**.

El sistema analiza el comportamiento y la posición de una persona para identificar posibles situaciones de caída.

### Objetivo

Detectar rápidamente posibles caídas para facilitar una respuesta oportuna.

### Características

* 📹 Análisis mediante cámara.
* 🤖 Procesamiento mediante Inteligencia Artificial.
* 🧍 Detección de personas.
* 🚨 Identificación de posibles caídas.
* 📊 Integración con el sistema de supervisión.

# 🛡️ Detección de Equipo de Protección Personal

Uno de los enfoques de **Zoren Solution** es la verificación automática del **Equipo de Protección Personal (EPP)**.

La Inteligencia Artificial puede analizar si una persona cuenta con los elementos de seguridad requeridos.

### Elementos que podemos verificar

| Elemento      | Detección |
| ------------- | --------- |
| ⛑️ Casco      | ✅         |
| 🦺 Chaleco    | ✅         |
| 🧤 Guantes    | ✅         |
| 😷 Mascarilla | ✅         |
| 👷 Persona    | ✅         |

Esto permite utilizar cámaras como una herramienta adicional para **supervisar el cumplimiento de medidas de seguridad**.

---

# 🖐️ Detección de señas

Otra aplicación de nuestro sistema es el análisis de **señas o gestos mediante visión artificial**.

La cámara captura el movimiento y la Inteligencia Artificial analiza los patrones visuales para determinar si corresponde a una señal previamente configurada.

Esto puede utilizarse como una herramienta de comunicación o supervisión dependiendo del entorno donde sea implementada.
